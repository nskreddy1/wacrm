## Candidates

| Concept | File | Idea |
| --- | --- | --- |
| 1 — Apex | `concept-1-apex.svg` | Solid geometric A; a single Signal diagonal cuts through it to form the X. Technical / premium / immediately recognizable. |
| 2 — Augment | `concept-2-augment.svg` | Base plane + offset rising plane sharing one vertex ("one becomes two"). Abstract / enterprise / mysterious. |
| 3 — Axis | `concept-3-axis.svg` | One unbroken stroke drawing A and X as a ligature. Brand-story continuity with the original "continuous stroke" idea. |

Review at `/brand-concepts` in the app: each mark is shown at 160/48/32/24/16 px,
on dark and light surfaces, in two-tone / monochrome / Signal-only / black-only /
white-only variants, plus the horizontal lockup. A mark that only works at 128 px
is a poster, not a product mark — judge at 16 px first.
